# کویر سریع — نسخه آزمایشی اندروید

این پروژه یک نمونه اولیه Android WebView است که صفحه محصولات کویر تایر را داخل برنامه باز می‌کند، سایز/مدل هدف را ذخیره می‌کند و در صورت مشاهده عبارت «افزودن به سبد خرید» در متن صفحه، اعلان می‌دهد.

## محدودیت‌های مهم
- این نسخه خرید خودکار، افزودن خودکار به سبد، انتخاب درگاه یا پرداخت انجام نمی‌دهد.
- بررسی هر ۵ ثانیه فقط وقتی صفحه برنامه باز و فعال است انجام می‌شود؛ اندروید ممکن است اجرای پس‌زمینه را متوقف کند.
- تشخیص موجودی بر اساس متن صفحه است و ممکن است محصول دیگری را هم ببیند؛ حتماً صفحه را خودتان بررسی کنید.
- هیچ رمز پیامکی یا اطلاعات بانکی خارج از سایت دریافت نمی‌شود.
- پیش از هر خودکارسازی خرید باید شرایط استفاده سایت و رفتار واقعی صفحه بررسی شود؛ درخواست‌های پرتکرار می‌توانند باعث محدودیت شوند.

## ساخت APK
1. Android Studio را نصب کنید (نسخه‌ای سازگار با Android Gradle Plugin 8.7.3 و JDK 17).
2. پوشه پروژه را باز کنید.
3. منتظر بمانید Gradle Sync کامل شود.
4. از منوی Build گزینه Build APK(s) را انتخاب کنید.
5. APK آزمایشی از مسیر `app/build/outputs/apk/debug/app-debug.apk` قابل دسترسی است.

## استفاده
1. برنامه را باز کنید و سایز را بنویسید، مثلاً `185/65R14`.
2. در صورت نیاز مدل را بنویسید؛ خالی گذاشتن آن جست‌وجو را عمومی‌تر می‌کند.
3. «ورود به سایت کویر تایر» را بزنید و ورود/کد پیامکی را خودتان انجام دهید.
4. صفحه محصولات را باز نگه دارید و «شروع بررسی دستی» را بزنید.
5. برای توقف، از دکمه برگشت و خروج به صفحه اصلی استفاده کنید.

## نکته
این بسته سورس پروژه است، نه APK آماده؛ ساخت APK نیاز به Android Studio/Gradle دارد.

## انتشار در GitHub و ساخت APK خودکار
این مخزن فایل Workflow دارد. پس از ایجاد یک مخزن GitHub با نام پیشنهادی `kavir-quick` و بارگذاری فایل‌های این پروژه در شاخه `main`:
1. وارد تب **Actions** در مخزن شوید.
2. گردش‌کار **Build Android APK** را باز کنید.
3. پس از سبز شدن اجرا، در بخش **Artifacts** فایل `kavir-quick-debug-apk` را دانلود کنید.
4. فایل ZIP دانلودشده از GitHub را باز کنید تا `app-debug.apk` را ببینید.

این APK آزمایشی/Debug است، نه نسخه امضاشده نهایی برای انتشار فروشگاهی.
